Conditional Statements
-control the flow (order) in which a Python program executes.
-make decisions, repeat code, or change the normal flow.
1.simple if - when have only one Condition
2.if else - one condition , two actions
3.elif ladder - more than one condition
4.Nested if - if inside if
----------------------------------------------------------------------------
Syntax of simple if
if condition:
    #Statements
-----------------------------------------------------------------------------------
syntax of if else
if condition:
    #statement1
else:
    #statement2
-----------------------------------------------------------------------------------
syntax of elif ladder
if Conditional:
    #Statements
elif Condition:
    #Statements
................
else:                   (optional)
    #Statements 
--------------------------------------------------------------------------------------
syntax of nested if:
if condition:
    if condition:
        #Statements
    else:
        #Statements
elif condition:
    #Statements
else:
