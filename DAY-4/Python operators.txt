Python operators
----------------
1. arithmetical operators  
      addition(+)
      subtraction(-)
      Multiplication(*)
      division(/)
      modulus(%)
      floor division(//)
2. comparison operators
	solution for this operators is a Boolean value
	less than (<)
	greater than (>)
	less than or equal to (<=)
	greater than or equal to (>=)

3. relational operators
	and - all the operations should be TRUE
	or - any one operation should be TRUE
	not - TRUE - FALSE , FALSE - TRUE
4. membership operations  
	checks whether the value is present in or not in and gives a Boolean value as output
